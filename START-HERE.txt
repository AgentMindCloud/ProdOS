ProducerOS 0.2.1 - Windows preview
=================================

ProducerOS helps organize music projects, versions, rights and releases.
Your music stays on your computer. The app works offline after setup.

DOWNLOAD
--------
Visit https://prodos.tech/ or the GitHub preview release:
https://github.com/AgentMindCloud/ProdOS/releases/tag/preview-0.2.1

Download ProducerOS-0.2.1-Windows.zip. No GitHub account is needed.
Use the release download, not GitHub's Code > Download ZIP button.
The installer bundled in the source tree is the older 0.1.0 version.

OPEN THE APP
------------
1. Right-click the downloaded ZIP and choose Extract All.
2. Keep the complete extracted ProducerOS folder together, including _internal.
3. Open that folder and run ProducerOS.exe. Do not run it from inside the ZIP.
4. Your browser opens the app on your own computer. Create your local login.
5. Start with a test project. Set its root folder to the folder containing
   that project's files. Register existing assets to organize and preview them.

You do not need to install Python. This portable preview does not create
desktop shortcuts or run an installation wizard. Remember your local password.

IF YOU ALREADY USE AN OLDER VERSION
---------------------------------
Make an app backup and a separate backup of your music first. Quit the older
app through its Settings page before opening the preview. Closing a browser
tab alone does not stop the app. Clean-machine upgrades have not been verified.

WHAT TO EXPECT
--------------
This is an unsigned early preview, built and tested on one Windows computer.
Other computers and very large music libraries still need testing. Windows
may warn about an unsigned app; check that the file came from the official
website or repository before deciding whether to open it.

App backups contain the database, not your music. Back up your audio, artwork
and DAW projects separately. File-management operations require your review
and approval; scanning itself does not change your music files.

FEEDBACK AND SHARING
--------------------
Share https://prodos.tech/ with your friend instead of emailing the ZIP.
Feedback: https://github.com/AgentMindCloud/ProdOS/issues
A GitHub account is needed to submit feedback, but not to download the app.

Keep using your DAW to make music. ProducerOS organizes the work around it.
It does not publish releases, send messages or upload your music for you.
